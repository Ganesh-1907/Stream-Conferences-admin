## 1. PROJECT SUMMARY

Stream Conferences is a global organizer of scientific, technical, medical, engineering, and academic conferences and webinars. `domain.com` is the **parent brand hub**: it introduces the organization, hosts webinars, showcases the photo gallery, and will house a Journal and a Proceedings section (coming soon). Every individual conference gets its own microsite at `subject.domain.com`, built from the same design system.

Tone: scientific, credible, editorial, structured, information-dense but scannable, with confident orange CTAs so visitors always know the next action.

Build as a responsive, accessible, production-quality site with a fully working light/dark theme toggle (instant switch, no flash-of-wrong-theme, defaults to system preference).

## 2. DESIGN SYSTEM — IDENTICAL ACROSS BOTH SITES

### 2.1 Color tokens

**Light mode**
- Page background: `#F9F6F2` (warm off-white)
- Primary navy: `#1B3255` — headings, hero, navigation
- Body text: `#18273F`
- Teal: `#1596A8` — science/technology accents, links, icons
- Orange CTA: `#F68F31` — Register / Submit / primary action buttons
- Card background: `#FCFAF7`
- Borders: `#D1D6DF`
- Muted text: slate gray (`#6B7280`)

**Dark mode**
- Page background: `#0D1426`
- Card background: `#151F32`
- Primary text: `#F3F0E8`
- Teal: bright cyan-teal (`#2FE0D6`)
- Orange CTA: `#F9933D`
- Borders: `#2D374F`
- Muted text: cool gray-blue (`#9AA5C0`)

**Brand feeling:** scientific + credible + innovative.
- Navy = trust and authority
- Teal = research, healthcare, technology
- Orange = energy, action, conversion
- Warm off-white = editorial, premium, readable

Theme toggle in the header (sun/moon icon), instant cross-fade on all tokens, persisted for the session.

### 2.2 Typography (same as subject.domain.com)
- Headings: "Sora" or "Poppins", semi-bold/bold, tight tracking — set in **Primary navy** (light mode) / **Primary text** (dark mode), with key words highlighted in **Orange** for emphasis (e.g., in hero headlines).
- Body: "Inter", regular/medium.
- Scale: H1 48/56 (mobile 32/40), H2 36/44, H3 26/32, Body 16/26, Small 14/20.
- Container max-width 1200px, 24px gutter mobile / 64px desktop.

### 2.3 Spacing & shape (same as subject.domain.com)
- 8px base grid; section vertical padding 96px desktop / 56px mobile.
- Card radius 16px, button radius 10px, input radius 8px.
- Light mode elevation: soft shadow `0 4px 20px rgba(27,50,85,0.08)`. Dark mode: 1px border instead of shadow.

### 2.4 Shared components — build/reuse identically on both sites
1. **Sticky header** — logo left, nav center, theme toggle, orange "Register Now" button on the right, hamburger + slide-in drawer on mobile, **persistent orange Register button pinned to the bottom of the screen on mobile**.
2. **Buttons** — primary orange filled (CTA), secondary navy outline, teal text/ghost link, all with hover-darken and focus-ring states.
3. **Cards** — consistent radius/shadow/hover-lift (`translateY(-4px)` + shadow increase) for conference cards, webinar cards, blog/journal cards, gallery cards.
4. **Tabs / segmented toggle** — for Upcoming/Past listings.
5. **Carousel/marquee** — auto-scrolling logo strips and image galleries, pausing on hover/touch, respecting `prefers-reduced-motion`.
6. **Countdown timer** — 4 large elevated number tiles (Days/Hours/Minutes/Seconds), same visual style as the microsite's countdown, used here for the next flagship webinar/conference.
7. **Scrolling theme banner** — slim ticker strip, orange/teal divider styling, looping the tagline "Connecting Minds, Advancing Science."
8. **Accordion** — for FAQ-style or "coming soon" detail blocks.
9. **Forms** — text/email/phone/select/textarea, consistent floating/top labels and validation states.
10. **Modal/Lightbox** — gallery image zoom.
11. **"Coming Soon" panel** — a reusable empty-state component: icon, heading, one-line message, optional email-notify input ("Get notified when this launches"). Used for Journal and Proceedings.

## 6. TECH NOTES FOR THE BUILDER TOOL

- Every webinar card and the header CTA should link with a placeholder pattern to the conference/webinar's own microsite where relevant: `https://{event-slug}.domain.com`.
- Keep the Journal and Proceedings pages as fully styled, on-brand "coming soon" experiences rather than blank stubs.
